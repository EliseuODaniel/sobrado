# Ativos fotográficos industriais

Modelos, texturas e HDRI do [Poly Haven](https://polyhaven.com/license), licença CC0-1.0. O manifesto registra URL oficial, página do ativo, bytes e SHA-256 de cada arquivo. As malhas são importadas como coleções nativas, com hierarquia original; seus recursos usados ficam empacotados no modelo final.

Alguns recursos foram avaliados e não usados: fern_02, desk_lamp_arm_01 e a resolução 2k do sofá. Permanecem como biblioteca de alternativas, separados dos objetos ativos. A luminária de mesa final é modelagem própria. O HDRI representa iluminação e contexto ilustrativo; não é o exterior real do imóvel. O conjunto herdado de materiais e cadeiras fica em `assets/industrial-v02/`, reutilizado como fonte técnica.
