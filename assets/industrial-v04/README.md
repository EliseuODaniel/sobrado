Recursos obtidos pela API oficial do [Poly Haven](https://polyhaven.com/license), licença CC0-1.0. O manifesto registra URL, tamanho, MD5 do fornecedor e SHA-256 verificados antes da gravação. `scripts/fetch_industrial_v04_assets.py` recusa substituir um arquivo existente com conteúdo diferente.

| Ativo | Aplicação nesta versão |
| --- | --- |
| [Modern Arm Chair 01](https://polyhaven.com/a/modern_arm_chair_01) | Geometria e UV das almofadas extraídas e adaptadas para sofá contemporâneo e quatro cadeiras; estrutura e costuras próprias |

| [Calathea Orbifolia 01](https://polyhaven.com/a/calathea_orbifolia_01) | Apenas a maior touceira, isolada do conjunto de cinco variantes; vaso modelado no projeto |
| [Slate Floor 03](https://polyhaven.com/a/slate_floor_03) | Cor, rugosidade e normais de peças quadradas do bar, com ajuste de tom |

A biblioteca anterior em `assets/industrial-v02/` e `assets/industrial-v03/` continua sendo fonte dos materiais e objetos herdados. O arquivo final empacota as imagens usadas e não depende de bibliotecas vinculadas. Os arquivos baixados permanecem intactos; as alterações acontecem nas cópias nativas da cena.
